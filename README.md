# 5 ночей у 6 школі

3D-горор про нічного охоронця ЗОШ №6 (Вінниця).

### ▶ ГРАТИ: https://gonoleksiy.github.io/five-nights-at-school-6/

Відкривається просто в браузері — нічого встановлювати не треба.
Можна також завантажити репозиторій і відкрити `index.html` подвійним кліком.

`models.html` — переглядач усіх персонажів і їхніх поз.

---

## Як запустити

1. Відкрий `index.html` (Chrome / Edge / Firefox).
2. Клікни «ПОЧАТИ ЗМІНУ» — звук вмикається після першого кліка (правило браузерів).
3. Прогрес ночей зберігається в браузері автоматично.

Потреби в інтернеті нема: three.js лежить локально в `vendor/`.
Онлайн підтягуються тільки шрифти — без них гра теж працює.

## Ти — охоронець

Ти сидиш у ніші, яка виступає з південної стіни верхнього коридору — спиною до Столової,
обличчям до входу. Столову видно ТІЛЬКИ на CAM 05: позаду тебе глуха стіна,
в ній лише вентиляційний лаз біля підлоги. Зі стільця не встаєш.
Дожити треба з 00:00 до 06:00 (≈5 хвилин реального часу на ніч).

**Ключова механіка огляду — три положення:**

| Положення | Що видно | Чим ризикуєш |
|---|---|---|
| **Сидиш** (за замовчуванням) | тільки нутрощі столу й три монітори | входу й коридорів НЕ видно взагалі |
| **Встав / визирнув** (`V` або ПКМ) | вхід крізь панорамне скло, гирла обох коридорів | ти на видноті, і руки зайняті — камери недоступні |
| **Під столом** (`Space`) | нічого | не керуєш нічим: ні шторами, ні ліхтарем, ні камерами |

Коридори — тільки через камери або коли стоїш із ліхтарем.

### Керування

| Клавіша | Дія |
|---|---|
| Миша | крутити головою |
| `V` / ПКМ | встати, визирнути через прилавок |
| `Space` | залізти під стіл |
| `Q` / `E` | ліва / права рольставня |
| `R` | ґрати вентиляційного лаза за спиною |
| `F` | ліхтар |
| `Tab` | планшет камер (`1`–`6` — перемикання) |
| `1` `2` `3` | здалеку ввімкнути світло: лівий коридор / правий / тамбур |

Живлення одне на всю ніч. Жере все: штори, ліхтар, камери, світло в коридорах.
На 0% штори відкриваються самі, ліхтар гасне, і Гліб іде до тебе гарантовано.

## Персонажі

| Хто | Що робить | Як рятуватись |
|---|---|---|
| **Гліб** | не замовкає — чутно, з якого боку йде | опустити штору з того боку |
| **Тітова** (директорка, історія) | штори їй не перешкода, у неї ключі | залізти під стіл; якщо побачила — усне опитування (дата з історії, 6.5 с) |
| **Копилов і Копилова** (географія + біологія) | ходять тільки разом, заходять з двох боків **одночасно** | закрити обидві бічні штори в одне вікно часу |
| **Ксан Павлвна** (математика) | тихо кладе на стіл самостійну | розв'язати задачу за 7.5 с; ні штори, ні стіл не допоможуть |
| **Костік** (кібербезпека) | рідко з'являється на камері | клікнути по ньому → зламає шкільне радіо, дасть дзвінок на урок: усі розвертаються, +12% живлення, 20 с тиші |
| **Назар** (математика) | рідко на камері | клікнути → шпаргалка: наступне опитування/самостійна автоматом + 22 с видно всіх |
| **Сніговик** | пасхалка в стилі Golden Freddy — просто з'являється в ніші | відвести погляд протягом 2 секунд |

Складність по ночах — у таблиці `AGGRO` в `src/game.js`.

## Стиль

- Рендер у низькій роздільності з апскейлом (`PIX` у `game.js`) + зерно, скан-лінії, віньєтка.
- Персонажі навмисно спотворені: задовгі двосекційні руки нижче колін, тонкі ноги.
  Копилови — 2.58 м заввишки, голова матеріально чорна й не влазить у конус ліхтаря.
- Стіл змодельовано за фото реальної рецепції школи: кутовий корпус зі світлого бука,
  піднятий прилавок із глухою надбудовою (саме вона закриває огляд сидячи),
  всередині — робоча поверхня з трьома моніторами, під нею — ніша.
- Монітори показують **живий фід** активної камери (рендер у текстуру).

## Звук

Усе синтезується в браузері, жодного аудіофайлу:
гул будівлі, вентиляція, кроки з панорамуванням по позиції, рольставні, дзвінок,
серцебиття, крик. Історії Гліба озвучуються через `speechSynthesis`
(якщо в системі є український голос; інакше — тихо, тільки субтитри).

## Історії Гліба

`src/stories.js` — комбінаторний генератор: 5 шаблонів × десятки слотів
(рік, місце, союзники, вороги, зброя, розв'язка) ≈ мільйони варіантів, повністю офлайн.

Можна підключити безкоштовну ШІ, щоб історії ще й генерувались зовні:

```js
Stories.setAI(function () {
  var p = encodeURIComponent('Напиши одну абсурдну коротку історію українською від імені школяра Гліба, 2-3 речення, без пояснень.');
  return fetch('https://text.pollinations.ai/' + p).then(function (r) { return r.text(); });
});
```

Вставити в консоль або в кінець `game.js`. Якщо запит не пройде — гра мовчки
відкотиться на офлайн-генератор.

